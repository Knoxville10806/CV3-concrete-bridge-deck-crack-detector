# GET 324 Mini-Project — Concrete Bridge Deck Crack Detector

Binary image classifier distinguishing Cracked from Non-cracked concrete
bridge deck surfaces, built for the GET 324 Laboratory Exercise 10
mini-project (Group CV3).

## Model
MobileNetV3Small transfer learning, trained in TensorFlow/Keras.
Test accuracy: 91.0% (Cracked recall: 64.3%, precision: 72.3%).

## Dataset
SDNET2018 (Kaggle), Bridge Deck (D) subset only — Cracked vs Non-cracked.
